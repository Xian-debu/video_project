# 事实核查台账（fact-ledger）

> 状态：🧭 规划期建立模板（2026-10-29）。每产出一集，追加该集用到的**外部事实**。
> 说明：本台账只管「不是我们本机算出来的事实」（原文断言、论文结论、公开数据规模）。
> 本机算出来的数字不在此表——它们在 ts-base 的 `inventory/evidence/` 里，由 claims.json 指向。

## 字段

| 字段 | 含义 |
|---|---|
| `id` | F001 起连续编号 |
| `claim` | 一句话断言（进入旁白或画面的原文） |
| `value` | 数值（若纯定性写 "定性"） |
| `source` | 出处：`书 p.XX` / `作者+年份+标题` / `URL` |
| `status` | `已核实`（看过原文/论文原文）/ `待核实`（转述或二手）/ `存疑`（与其它来源冲突） |
| `used_in` | 用在哪些集（slug） |
| `note` | 冲突说明、换算、限定条件 |

## 纪律

1. `status = 待核实` 的条目**不得**以断言形式出现在画面或旁白里；只能作为"据说/书中称"并标注。
2. 任何 `存疑` 条目必须在 `note` 写清冲突双方，并在视频里显式说明。
3. 每个进入画面的外部事实，必须在 `claims.json` 里有一条对应记录（即使 value 是定性）。
