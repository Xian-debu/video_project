## Thesis

第 48 集把无标签窗口变成了可用特征；这一集换一个方向：不改数据，只**改表示**。池子是沪深 300 快照里的 **20 只股票**（每个行业门类一只），窗口 **128 根日线**、步长 5，共 **8,531 条**候选窗口；标签是未来 **20 个交易日**对数收益的三分位（训练池 下行 1,935 / 震荡 1,854 / 上行 1,883），多数类基线 **0.3333**。四种编码（GASF / GADF / MTF / 递归图）都是**双射**：GASF 的对角线可以反解出幅值，min-max 前置后反解误差 **4.471e-15**；但那句话到此为止——同一批窗口上，GASF 的 Fisher 判别比 **0.0139**、MTF **0.0059**，相差 **2.3559 倍**，说明两个通道的偏置确实不同；可把这个偏置喂给一个 **687 / 787 参数**的卷积网，20 轮后 GASF **0.3517**、MTF **0.3633**、双通道 **0.3133**，三条全在三分类的随机带里，**双通道没有超过任一单通道**。四域加权投票同样落空：时域 / ACF / 谱域 / shapelet 的测试准确率 **0.3456 / 0.3444 / 0.3200 / 0.3211**，权重 **0.2607 / 0.2472 / 0.2397 / 0.2524**，COTE **0.3322** 低于最好的单域 **0.3456**，也低于等权 **0.3367**。所以本集的结论是两层：**图像化是双射，但双射不等于有用；多域集成的前提是至少两个域真的强，四个弱域加在一起还是弱**。

## Verification

看完能自己复现：

1. **四组黄金值手算**：GASF 在 x̃ = [0,1] 上 → **[[−1, 0], [0, 1]]**（cos 0°、cos 90°、cos 90°、cos 180°）；GADF → **[[0, 1], [−1, 0]]**（对角恒 0、反对称）；MTF 在 Q = 2、分箱 [0,1,0] 上 → **[[0,1,0],[1,0,1],[0,1,0]]**（行和 1）；RP 在 x = [0,1,2] 上：ε = 0.5 → **单位阵**、ε = 2.5 → **全 1**。计划里 RP 的 ε = 1.1 那组与定义 |xi − xj| < ε 自相矛盾（|0−2| = 2 > 1.1），按标准定义实现、测试改用上面这组（见 Deviations）。
2. **双射：从对角反解幅值**：|x̃j| = sqrt((Gjj + 1) / 2)，逐位比较。窗口先 **min-max** 压到 [−1,1] → 误差 **4.471e-15**（浮点极限）；换成 z-score + clamp → 误差 **1.695**（尾部被截断，信息真丢了）。符号反不回来，要靠 GADF 联合定——这是本集最重要的实现细节。
3. **偏置：Fisher 判别比**：同一批窗口上 gasf **0.0139** / gadf **0.0114** / mtf **0.0059** / rp **0.0076**，四个值都是有限正数；GASF ÷ MTF = **2.3559**，量级上不是 1。这是「幅值通道和转移通道编的不是同一件事」的直接证据。
4. **卷积：三条通道都在随机带**：2,400 条训练 / 1,200 条测试、20 轮、Adam + 种子 7，GASF **0.3517**、MTF **0.3633**、双通道 **0.3133**，全部落在 **0.28–0.39** 的随机带里；双通道比两条单通道都低（**负结果**，照实记录）。
5. **参数量对账**：单通道 **687**、双通道 **787**，差 **100** = 4 个核 × 25 个权重，正好是第一层输入通道翻倍多出的部分；这个差值可解释，通道之间的比较才公平。
6. **加权投票黄金值**：三个域准确率 0.8 / 0.9 / 0.6 → 归一权重 **0.3478 / 0.3913 / 0.2609**（Σ = 1）；预测 [0, 1, 1] → 类 0 得 **0.3478**、类 1 得 **0.6522**、类 2 得 **0**，投出 **类 1**（原始尺度上是 **0.8 vs 1.5**）。平票取更小的类号；某个域准确率为 0 或 NaN 时权重归零，其余域照投。
7. **多域集成的负结果**：四个域都接近随机（0.3200–0.3456）时，COTE **0.3322** 不低于最差单域（0.3200），但也**超不过最好单域**（0.3456），并且低于等权基线 **0.3367**。证据程序 **28 组检查全过、耗时 476.9 s**，分组 data 5 / encode 6 / image 2 / fisher 2 / cnn 5 / cote 5 / demo 3。

屏幕上必须出现：−1 / 0 / 1 三组黄金矩阵、**0.0139** 与 **0.0059**、**2.3559**、**0.3517 / 0.3633 / 0.3133**、**687 / 787**、**0.3322 / 0.3456 / 0.3367**、四域权重与四联图、28 组检查。

## Boundary

1. **二十只股票不是二十个行业面板**：每个门类只取一只（有效交易日最多的那只），所以「20 个行业」实际是 20 只股票、20 条时间序列。换成别的股票，Fisher 与准确率的绝对值都会变；这一集比的是同一批窗口上的**相对差异**，不是行业结论。
2. **窗口重叠，有效样本没那么多**：长度 128、步长 5，相邻窗口共享 123 根日线；训练池 5,672 条按独立段折算只有约 **222 条**独立信息。8,531 听起来大，实际小得多，所有准确率都要按这个打折扣。
3. **标签本身接近随机，负结果只能到此为止**：20 日方向三分位本来难预测，四条通道全在 0.31–0.36。这能说明「这套表示 + 这个小网络没有把标签信息抬起来」，**不能**说明「图像化一定没用」——换标签口径（波动率、趋势强度）、换网络规模、换训练预算，结论都可能不同。这一集只报方向，不做显著性检验，也不给置信区间。
4. **网络很小、只跑一个种子**：687 / 787 个参数、20 轮、学习率 0.01 固定；没有超参搜索、没有多种子平均、没有和发表结果对齐。它是一把尺子，量的是「同一预算下三种通道谁更能用」，不是 SOTA 对比。
5. **不是交易系统**：没有成本、没有滑点、没有仓位，2022 年切分之外没有第二个样本外区间。COTE 的权重来自训练池尾部验证集，本身也有选择偏差。

## Deviations

1. **股票选择**：计划「按日均成交额取前 20 只」；实际 `bars_daily.amount` 全 NULL，改行业分层（20 个门类各取有效交易日最多的一只），偏差写进导出 manifest 与 ts-admin SELF-AUTH A20。
2. **窗口前置归一化**：计划未提；窗口在 CSV 里存的是 z 分数，直接喂 GASF 会被 clamp 截断，所以编码前显式 min-max 到 [−1,1]。两种口径都测了：min-max 反解误差 4.471e-15、z-score + clamp 1.695。
3. **RP 黄金值更正**：计划写「x = [0,1,2]、ε = 1.1 → 全 1；ε = 0.5 → [[1,0,1],[0,1,0],[1,0,1]]」，与标准定义 |xi − xj| < ε 矛盾（|0−2| = 2 > 1.1）。按标准定义实现，测试改用 ε = 2.5 → 全 1、ε = 0.5 → 单位阵。
4. **CNN 抽样**：计划「全量 5,672 条训练」；实际按类均衡抽 2,400 训练 / 1,200 测试（证据程序的时间预算），抽样列 `cnn = 1` 写进 CSV。
5. **COTE 分类器**：计划「每域训练一个分类器」；实际每域一套手工特征（7 / 12 / 8 / 8 维）+ **最近质心**，权重用验证集准确率，其余照计划。
6. **时长**：计划 22 分钟；成片 **24:03.75**（1,443.75 s）。历史区间 E43 18.8 / E44 21.5 / E45 21.5 / E46 23.1 / E47 20.5 / E48 24.1 分钟，计划分钟是粗估，实测 ±30% 正常，不改稿。
