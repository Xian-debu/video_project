# 43-shapelet-search-pips - Shapelet：从一条序列里挖出一小段判别力

## Thesis

在合成错位 motif 数据上，PIPs 把候选子序列压到 9.82% 之后，Top-1 Shapelet 的信息增益与全搜索相差 0.0000 bit，搜索耗时降一个数量级（10.21×）——省下来的时间一点判别力都没花掉；但在真实收益窗上，同一个算法只比随机猜高 0.96 个百分点。

## Verification

看完能自己复现：① 在合成 motif 上跑出 Top-5 Shapelet 及其增益（三分类一对其余上界 0.9183 bit、实测 0.8475 bit，两类平衡上界 1.0、实测 0.8938）；② PIPs 把候选压到 9.82% 后的增益损失 0.0000 bit 与 10.21× 加速；③ F 与 H 两张检验表，并指出结论不一致的组（黄金 H 例 H=3.857143 p=0.145356 不显著；离群点反例 F p=0.487704 不显著而 H p=0.044502 显著）。屏幕上必须出现：0.8475（与 0.9183 / 1.0 两个上界并列）、9.82%、3.857143、13.5。

计划原文写「最优应为 1.0 bit 附近」——这是把两类平衡上界当成了三分类目标。三分类一对其余的上界是 0.9183，实测 0.8475；1.0 只属于两类平衡对照（实测 0.8938）。处理方式：两个上界都上屏，把「上界」与「实测」拆开报。

## Data

合成主数据：3 类 motif，sin 周期 8/12/20，长度 100，每类 50 条，高斯噪声 0.1，相位随机 ±π（线性同余 LCG 1103515245·s+12345 mod 2^31 驱动，换机器逐位一样）；训练 90 / 测试 60。候选长度只试 8/12/20，起点数分别 93/89/81，合计 263 个起点 × 90 条训练序列 = 23,670 个候选。ts-admin 对照：全市场同门类各 50 只（电子 C39 / 医药 C27+C35 医药口径 / 装备 C35 装备口径），2018-01-02 至 2025-12-31，每只取最后 100 个交易日的 close 归一化序列，标签=门类；panel 1,942 行 × 150 列，sha256 前缀 0ccdea98。

## Algorithms

## Implementation

- ts-base 三模块纯 Haskell、无外部数值库：`src/TsBase/Algos/Ch05/Shapelet.hs`（19 测试）、`Pips.hs`（11）、`DistTest.hs`（14），合计 44 条新断言；证据程序 `app/Ch05ShapeletEvidence.hs`，命令行入口 `evidence-ch05-shapelet`。仓库现在 136 套 / 1,846 条断言、0 FAIL。
- 证据跑：`cabal run -v0 tsbase -- evidence-ch05-shapelet --data data/episodes/43-shapelet-search-pips --out data/episodes/43-shapelet-search-pips --evidence inventory/evidence`，23/23 PASS / 36.8 s。
- 主读数（合成）：全搜索 23,670 候选 / 22.15 s / 增益 0.8475 / 测试准确率 1.00；PIPs 起点限定在十个拐点，2,325 候选（9.82%）/ 2.17 s / 增益 0.8475 / 准确率 1.00 → 10.21× 加速、增益差 0.0000、省掉 21,345 个候选。
- 平局的两条路径不是同一个模板：全搜索最优起点是 8，PIPs 的拐点集合 [0,5,9,13,17,29,33,38,42,99] 里没有 8；Top-5 全是长度 8、全部来自第 1 条序列、全部对第 3 类分裂最好，阈值 1.0477–1.3458，增益全 0.8475——周期 8 的形状会重复出现，不同起点截出几乎一样的片段。
- 反向 shapelet 是机制不是 bug：最优模板来自第 1 类序列，却对第 3 类分裂最好（第 3 类的距离全部大于 1.2866，两类在 1.2036 以下）；本集分类器只用同类模板（`hitClass == LabelOf (train !! hitSeries)` 过滤），反向模板没有参与预测。
- 真实数据（150 只 × 最后 100 天，训练 45 / 测试 105）：搜索 8,190 个命中 / 4.68 s，最优增益 0.3983（长度 8、阈值 1.6709），准确率 0.3429（36/105），随机基线 0.3333，只高 0.96 个百分点。
- 两个检验：ANOVA F=3.5726 p=0.0305（组均值 1.3828 / 1.2037 / 1.2897），Kruskal H=9.2009 p=0.0100，都显著；但用 1.6709 去切，召回电子 39/50、假阳 91 条、精确率 0.30——检验显著 ≠ 一条模板能分类。
- 黄金小例：ANOVA 两组相同、第三组整体 +9 → SSB 270 / SSW 120 / df 2,12 → F=13.5、p=0.000849；Kruskal 三组 [1,3] / [2,10,12] / [4..9,11] → 秩和 4/24/50，H=3.857143、p=0.145356（不显著）。离群点反例：第三组放一个 100 → F p=0.487704（不显著）、H p=0.044502（显著）。
- 两类平衡对照：两类各 30 条、理论上界 1.0 bit、实测 0.8938（长度 8、阈值 1.0471、类 0 距离 0–0.9943、类 1 距离 1.0999–1.3449）；差的 0.1062 bit 来自「模板自己序列的自距离记无穷远、不参与分裂」——这是口径，不是噪声。
- 证据程序把每个读数同时写进 summary.json 与 `inventory/evidence/43-shapelet-search-pips.ch5-shapelet.json`；dist.json 由 build/make_dist_data.py 从证据 + panel 重算四个案例窗，与证据留一预测不一致即 abort。

## Boundary（不声称与欠账）

- 合成数据上的「零损失」是构造出来的：周期 8 的 motif 在一百个点里重复十余次，拐点集合虽漏掉起点 8，别处的同形状片段把答案补上了；换成周期 20 的长模板，起点就被拐点卡住（计划里预期、本集没有单独跑这个消融）。
- PIPs 的漏检率没有实验：十个拐点漏掉真正最优起点的频率「未测」，只在一个序列上看到「漏了 8 但被同形状片段掩盖」。这是边界页明写的未验证部分。
- 真实收益窗只有一个读数：训练 45 / 测试 105 来自 150 只股票、每只最后 100 天，样本间同涨同跌，有效样本远小于 105；0.3429 不能读成「Shapelet 在股票上没用」的普适结论。
- 检验与分类不是一回事：F/H 显著只说明三组距离均值/秩有差，不说明一条阈值能分开三类；精确率 0.30 是这一课的核心反例。
- 长度选择只试 8/12/20 三个值，没有连续搜索；PIP 个数固定十个；真实数据只跑全搜索（4.68 s），没有做 PIPs 对照。
- 欠账：① PIPs 漏检率实验；② 周期 20 长模板被拐点卡住的消融；③ 真实数据上的 PIPs 加速与增益对照；④ 反向模板参与预测的改进留给下一集把 min 换成 SoftMin。

## Deviations（与计划不同之处）

- 计划写「最优应为 1.0 bit 附近」，实测三分类一对其余上界 0.9183、实测 0.8475；1.0 是两类平衡数据的上界（实测 0.8938）。两个上界都上屏，不把上界当实测。
- 计划写沪深 300 里 150 只、2018-2024；C39/C27/C35 在沪深 300 内凑不出各 50 只，改全市场同门类各 50 只、2018-01-02..2025-12-31。偏差写进 ts-admin manifest、dist.json meta 与本页。
- 计划的 PIPs「候选压到 10%」实测 9.82%；增益损失 0.0000 bit，两条路径取到同一个模板（不同起点、同一形状），这一点在 metrics 段讲清「平局有运气成分」。
- 计划写「随机相位 ±π」，实现按此保留（与 E42 的固定相位相反）——随机相位帮助 DTW/Shapelet 证明形状价值，但也让合成数据比真实数据更「干净」。
- 证据检查 23 条（data 5 / synth 8 / real 5 / worked 5），耗时 36.8 s；检查逐条写 pass 文本，不是只报总数。
