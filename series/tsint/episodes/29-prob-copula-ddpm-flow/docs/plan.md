## Thesis

生成式概率预测的三条路，都在做同一件事：把简单随机源搬成目标分布。Copula 用秩变换把每条边缘搬到正态，再靠相关矩阵拼联合；扩散用一千步加噪把数据推成噪声，再学一个去噪器反着走；连续流用可逆映射搬整条密度，换元公式给出精确对数似然。三种代价完全不同：Copula 是一次矩阵分解加秩变换，扩散是 T 次网络前向，连续流是 ODE 积分加 log-det。本集三个模块都实现、都测过，二十四个检查点全部通过；但不训练成预测器、不报生成质量——DDIM 的二十条路径样本标准差 62.7 而数据只有 2.3，这个配置只够验证损失与可复现。

## Verification

不报 FID / CRPS，只测闭式值、恒等式、可逆性与真实数据上的读数。24 项检查全部通过（24/24），底层 99 套测试 / 1,371 条断言零失败（本集新增 58 条：Copula 22、扩散损失 21、连续流 15）。

- 高斯 Copula（22 条断言）：PIT 后正态分数对称，合成样本 KS 距离 0.0105（<0.05），独立时 Kendall τ 偏差 0.0035、Spearman ρ 偏差 0.0062（|·|<0.02）；ρ=0.5 的闭式值 C(0.5,0.5)=1/4+arcsin(0.5)/(2π)=1/3=0.333333，书里的计划写 0.583333，已证其违反 Fréchet 上界 min(u,v)=0.5，测试同时钉住 1/3 与「0.583333 越界」；相关矩阵加 1e-6 抖动后 Cholesky 成功，边缘往返误差 0.0142，八通道面板拟合误差 0.0525（离散相关取整导致，状态「右」）；真实面板同行业收益相关 0.6760 vs 跨行业 0.3848，窗口内 0.6988 vs 0.5517。
- 扩散噪声损失（21 条断言）：前向闭式 x_t(0.5)=1.4142135624（=√2，t=500、x0=1 的闭式）；ε_θ=ε 时 oracle loss 0、ε_θ=0 时 loss 1.0；同 seed 两次采样 loss 0.9588835408 完全相同，换 seed 1.10252755；训练 400 步 loss 0.9986 → 0.7649；aBar(500)=0.078587、aBar(1000)=4.036e-5；DDIM 20 条路径全有限，但样本均值差 12.46、标准差差 64.87（数据 sd 2.3037、样本 sd 62.69）——这条当边界写，不当质量声明。
- 连续流（15 条断言）：仿射层 log|det J| = log 2 = 0.6931471806（手算可验）；逆流往返误差 2.22e-16（机器精度）；一维高斯密度网格积分 1.0000000000（41×41 网格求和）；RK4 8 步误差 2.330e-6、16 步 1.379e-7，比值 16.889（理论 16，区间 [10,20]）；真实面板 1,000 个窗口 PCA 首成分占比 0.7953（特征值 5.127 / 1.235）。

## Boundaries

四条边界：一，本集没有训练成预测器——Copula 用经验边缘，扩散只训 400 步，连续流是小维度小场，所以不报 FID、不报 CRPS，任何「哪个生成器更好」的说法都不成立；二，DDIM 二十条路径的样本标准差 62.7 对数据 2.3，均值差 12.46，这个配置不构成生成质量的声明，只验证损失与可复现；三，行业结构随窗长变——整段同/跨差值 0.29，窗口内只剩 0.15，行业在哪不能从单一窗长下结论，相关也不等于因果；四，原文缺口——书里只点名三种方法、没有公式，文献编号要回 PDF 核，计划里的闭式值 0.583333 也写错了，本集双登记。三笔欠账：算法卡没写、demo 子命令没做、端到端训练没做；都不影响本集「结构可测」的交付。
