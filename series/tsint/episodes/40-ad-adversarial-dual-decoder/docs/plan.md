## Thesis

同一批无标签数据，三种让分数更稳的思路：对抗（USAD 让两个解码器互相挑错）、密度（DAGMM 在潜空间拟合 GMM 算能量）、集成（多个 AE 取中位数压掉个体噪声）——它们回答的是三个不同的问题：「不像自己」「不像正常分布」「多数模型都认为不像」。三种思路在测试段全部失灵，而且失灵方式各不相同，这一集的工作是把失灵拆开讲清楚。

## Implementation

- ts-base 三模块纯 Haskell，无外部数值库：`Ch04/USAD.hs`（354 行 / 9 测试）、`Ch04/DAGMM.hs`（456 行 / 10）、`Ch04/AEEnsemble.hs`（211 行 / 7），合计 1,021 行 / 26 个新测试；仓库 127 套 / 1,689 条。
- 手写前向、反向、EM、Cholesky。一次 OOM 事故：逐窗 SGD 写成惰性 zipWith，folds 只强制最外层构造器，四万次权重更新堆成 thunk 链，进程被 cgroup 杀掉（退出码 137，峰值 8.17 GB / 上限 12 GB）；修法是按阶段 `V.force` / `evaluate`，常驻降到 0.4 GB。
- 单测里专门做了反向训练器：符号翻反后方向性检查 `s3 < s2` 必须失败（正常 201 → 54，反向 0.02 / 0.10），证明检查测的是方法而不是噪声。
- 中位数偶数成员没有正中间，本集返回「中间两个平均 + 警告」，测试里钉住 `[1,2,100] → 2`（均值 34.33）与 `M = 1` 退化为单 AE。

## Boundary（不声称与欠账）

- 不声称 SOTA（无公开基准）、不声称通用（一只票、A 股、白酒）、不声称实时（日频收盘后批处理）、不声称集成更稳（实测反向）、不声称能量可比（负对数似然与重建误差没有换算关系）。
- 三条欠账：对抗训练没有收敛保证（L1 末值 2,377，本题固定 20 轮，没有回答早停指标）；集成只看到「掉下来」，没拆开每个成员的测试段表现；窗口重叠 99 天、1,228 个窗口非独立，F1 只报点估计，不报置信区间。
