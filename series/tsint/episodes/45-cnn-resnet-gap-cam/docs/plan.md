# 45-cnn-resnet-gap-cam - 卷积、残差与 GAP：让分类器指出「哪几天在起作用」

> status: ready
> chapter: ch05 | runtime: 22 min target (actual 21:28.78) | algorithms: 3

## Thesis

第 44 集的模板能学，但模板是「一小段形状」，说不清它出现在第几天。本集把窗口直接喂给一维卷积：核在序列上滑动，同一组权重看遍所有位置；残差块给梯度留一条直路；全局平均池化（GAP）把任意长度压成一个向量，CAM 再把分类头权重乘回特征、摊回 60 天，画出一张「哪几天权重最大」的热图。实测三条结论：卷积比线性 softmax 高 3.9 个百分点（0.5880 vs 0.5494）；残差加深**没有**换来精度（四块 0.6266，一块 0.6609，掉 3.4 个百分点）；GAP-CAM 换来热图的代价是 9.9 个百分点（0.4893）。本集的可验证收益是可解释性，不是精度。

## Verification

看完能自己复现：

1. **卷积黄金值**：输入 [1,2,3,4]、核 [1,0,−1]、偏置 0，输出 [−2,−2]（第一个窗口 1×1+2×0+3×(−1)=−2）。
2. **池化**：窗口 2、输入 [1,3,2,5]，最大池化输出 [3,5]；平票 [2,2] 固定取索引 0。
3. **维度账**：60 → 53 → 26 → 19 → 9（核长 8、池化减半两次），展平 9×32 = 288。
4. **残差恒等**：捷径权重取零时，输入 [1,2,3] 原样回来；通道数变化时用 1×1 投影，[1,2] 变成 [2,4]。
5. **GAP 长度无关**：输入 [1,2,3,4] 的均值 2.5；同一套权重吃 60 步和 120 步，都输出 3 个 logits。
6. **CAM 归一化**：距离/权重 [0.5,1,1.5,2] 归一化到 [0, 0.3333, 0.6667, 1.0000]；真实样本特征长 53（60−8+1，valid 卷积）。
7. **真实 CAM**：股票 sh600130（标签 0），特征按感受野中心摊回 60 天，top-5 是第 52 / 51 / 53 / 50 / 54 天，热值 1.0000 / 0.9655 / 0.8985 / 0.8486 / 0.8062。
8. **六模型对照**：随机 0.3333、线性 0.5494、卷积 0.5880、四块残差 0.6266、一块残差 0.6609、GAP-CAM 0.4893。
9. **证据程序**：27 组检查全过，耗时 105.3885 s，分 data 6 / conv 4 / res 4 / gap 5 / cam 3 / train 5。

屏幕上必须出现：[−2,−2]、[3,5]、GAP=2.5、CAM 归一化 [0, 0.3333, 0.6667, 1.0000]、top-5 日索引（52/51/53/50/54）。

## Algorithms

- **ch5-cnn** — 一维卷积分类骨干（conv / pool / 反传 / 训练） (`TsBase.Algos.Ch05.Cnn`, 19 cases)
- **ch5-resnet** — 残差卷积网络（恒等捷径 / 1×1 投影 / 深网） (`TsBase.Algos.Ch05.ResNet`, 10 cases)
- **ch5-gap-cam** — 全局平均池化 + 类激活映射（GAP / CAM / 无 bias 线性头） (`TsBase.Algos.Ch05.GapCam`, 13 cases)

全仓库测试 142 套 / 1,938 条断言，本集新增 42 条（19+10+13）。

## Implementation

- `Cnn.hs`：conv1d / convFull / corr / poolForward / poolBackward / forwardCnn / backpropCnn / trainCnn / cnnAccuracy / flatCnn；形状用显式 `Shape { ch, len }` 一路带着走。
- `ResNet.hs`：resBlock / forwardRes / backpropRes / trainRes / resAccuracy；捷径只在通道数变化时加 1×1 投影。
- `GapCam.hs`：gap / forwardGapCam / camOf / minMaxNorm / topKIndices / trainGapCam / gapCamAccuracy；线性头**不带 bias**，否则热图整体平移。
- 本集踩过的坑：GHC-18932 让严格字段 `!V.Vector Double` 编不过，改成惰性字段；深 ReLU 网络整片死亡，stem 加 bias 0.5 才活；ResNet 反传漏掉两处 ReLU 掩码，梯度校验直接暴露。
- 反传两个必踩的坑：池化梯度只回 argmax 那一格（平票取 0）；卷积对输入做 full 卷积、对权重做互相关（`dInput = convFull (reverse w) g`、`dWeight = corr x g`），方向搞反形状先不对。

## Boundary

1. **数据口径**：计划「HS300 300 只、60 日 × 5 字段」；HS300 内 C39 只有 48 只、C27 13 只、C35 14 只，凑不出三类各 100，改为全市场同三个门类各 100 只，区间延到 2025-12-31。
2. **「加深没用」只在一档成立**：只比了一块和四块（0.6609 vs 0.6266），八块、十六块、瓶颈结构都没测，结论只能写成「这一档上加深不划算」。
3. **五个字段高度冗余**：开高低收四列近似线性（平均 |r| 0.7505），卷积比线性只高 3.9 pp 与这条对得上；想再往上得换字段，不是换结构。
4. **可解释性有代价**：GAP 把时间压成均值、位置信息被抹平，CAM 只能指出「模型看哪里」，不能当因果解释；热图代价 9.9 pp。
5. **一次训练、一个种子**：所有模型只跑 seed 7，没有多次初始化方差，也没有交叉验证；表里小数点后四位的差当噪声更稳妥。
6. **未验证清单**：八块/十六块深残差、空洞卷积、热图在不同种子下的稳定性、热图与真实事件（财报/公告）的对应关系。

## Deviations

1. **数据口径**：计划 HS300 内三类各 100 只、2018–2024；实际全市场同门类各 100 只、2018-01-02 至 2025-12-31（与第 43/44 集一致），筛选规则写死在 ts-admin 导出脚本里。
2. **残差没加分**：计划「残差让深层更强」；实测四块 0.6266、一块 0.6609，深的反倒低 3.4 个百分点。在这个窗口长度和样本量上，四块已经过了拐点。
3. **GAP-CAM 精度更低**：计划以精度为主、可解释性为辅；实测 GAP-CAM 0.4893，比卷积低 9.9 pp，本集结论改为「可解释性是真收益，精度是代价」。
4. **CAM 的日映射**：特征 53 个、日位置 60 个，按感受野中心（feature j → day j+3）摊回，不按均匀上采样；热图与 top-5 日索引因此对齐。
