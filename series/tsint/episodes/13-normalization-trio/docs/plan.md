# 13-normalization-trio - 归一化三兄弟：差别只在「用谁的统计量」

> status: producing
> chapter: ch02 | runtime target: 16 min | algorithms: 3

## Thesis

式(2.7) 的 RevIN 写成「先减均值除以标准差、再仿射」，用字面公式实现等于一个恒等层：实测字面版与输入的最大差 1.42e−14（双精度舍入），正确实现的 |X'−X| 最大到 78.74，两者差 16 个数量级。式(2.6) 的 DAIN 把 α/β 换成可学习的两层映射、再加一个门 γ；SAN 把统计量的粒度从「整段」缩到「一片 τ=25 步」，并用一个小 MLP 预测下一片的统计量。三个式子的形状几乎一样（减中心、除尺度），真正的分野只在「统计量从哪来」：整段、可学习、分片。

## Verification

看完这一集，观众应能解释为什么逐字实现式(2.7) 得到恒等层，并给出正确写法（存 mu/sigma，前向 X'=(X−mu)/(sigma+eps)，反向 X=mu+(sigma+eps)X'）；能写出 RevIN 与 Z-score 的区别（训练集固定统计量 vs 当前输入统计量、预处理 vs 模型内可逆层）；能清点 DAIN 的 12 个参数（W_a 3 + b_a 1 + W_b 3 + b_b 1 + W_c 1 + b_c 1 + 门 γ 2）并说明 eps 保护与 gate 开关；能说明 SAN 的 44 个参数（MLP 2→8→2 共 42，加 2 个残差缩放）与 τ=25 分片、残片丢弃；能读出三条桥接实测全为 0.00（RevIN eps=0 与 Z-score、DAIN 与 RevIN、SAN 与 RevIN 逐位一致）；能读懂真实数据判决：DAIN 拟合出 W_a=[1,0,0]、W_b=[0,1,0]（损失 9.59e−10），SAN 第一阶段 mu 误差 2.5073 / sigma 误差 0.3394，均**输给**「沿用上一片」基线 0.6893 / 0.2254（3.64× / 1.51×），片内 sigma 与整段 sigma 之比平均 0.3923。归一化是否解决漂移（否）、是否创造信息（否）由边界档说明。
