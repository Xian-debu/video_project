## Thesis

书里给出两个「结构的读数」，都没有配套的算法细节。

式(2.4) 把整张面板的相关结构压成一个数：`Corr = mean(p) + 1/(1+var(p))`。书里只有一句话、没有别的。四个选择全部没写：缺失值怎么处理、方差是总体还是样本、常数序列怎么办、变量对怎么数。这四个选择每一个都能让读数动，本集把它们全部写死（SELF-AUTH A33），然后发现真正反直觉的不是口径，是**权重的形状**：第二项 1/(1+var) 是**饱和项**——价格面板与收益面板的方差差 9.6 倍（0.1693 vs 0.0177），读数只差 0.1504（1.0684 vs 1.2188），因为这一项只从 0.855 走到 0.983。均值项有分辨率，越大的方差越被压扁。

STL 走另一条路：把一条序列拆成 X = T + S + R。**书里没有任何公式**——只有文字与图（printed p.22–25），参数与迭代次数都没有。所以本集的口径全部来自 Cleveland 等 1990 的原始定义（SELF-AUTH A34）：周期 5 → n_s = 7、n_t = 11、内循环 2 轮、外层鲁棒 0 轮、tricube 权重、端点局部线性。它的季节强度按式(2.2) 定义，式子只有一个，换的只是分母里的 R：LOESS 剩下的 vs 移动平均剩下的。同一个剖面（逐相位差最大 0.169 元）在两种方法下强度是 0.1596 与 0.0083，**差 19.2 倍**。

这一集最值钱的一句：**「季节强度」不是数据的属性，是数据加方法的属性**；「相关性读数」不是数据的属性，是数据加口径的属性。两条都进画面、进旁白。

## Algorithms

- ch2-correlation — 面板相关性指数（`TsBase.Algos.Ch02.Correlation`）：`pairwisePearson` 上三角枚举、配对完整、总体方差除以 K；少于 2 列返回 `Left (CorrTooFewVariables n)`、一对都算不出来返回 `Left (CorrNoValidPairs k)`，不返回 0。
- ch2-stl — STL 季节-趋势分解（`TsBase.Algos.Ch02.Stl`）：`defaultStlConfig period = StlConfig period ns nt 2`，`ns = nextOdd (max 7 period)`、`nt = nextOdd (ceiling (1.5*period/(1 - 1.5/nsD)))`；内循环一轮 = 去趋势 → 逐相位 LOESS(n_s) → MA(L)·MA(L)·MA(3) 低通 → s = c − lp → 去季节 → LOESS(n_t) 趋势；残差 = x − t − s。

## Boundaries

100 只票一年，够说明机制、不代表全市场；只报读数与分解，不做下游选股或预测；STL 只做周期 5 一个频率，两端一两个周期的结果不可信（照常输出但不拿端点下结论）；外层鲁棒迭代不实现，含离群点的序列强度会更保守；图2.6 的 1.988 / 0.752 无法复现，只作值域旁证。
