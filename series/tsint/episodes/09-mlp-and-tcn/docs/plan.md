# 09-mlp-and-tcn - MLP 与 TCN：从一行仿射变换到因果膨胀卷积

## Thesis

MLP 与 TCN 的差别不在深度，而在「谁能看见谁」：MLP 把窗口展平，第 k 个输入与第 k+1 个输入在权重矩阵里毫无关系；TCN 用因果卷积把「时间相邻」写进结构，于是 K=3、d=1,2,4 三层就能让最后一个输出看见前 15 步，且第 t 个输出永远看不见第 t+1 步。把式(2.62) 的核翻转写错，这个性质当场消失，而模型仍然能训练、损失仍然下降——只有因果性测试能抓住它。

## Verification

看完这一集，观众应能写出一个通过有限差分梯度检查的 MLP，并解释式(2.62) 为什么必须翻转核。屏幕上必须出现 4 个数字：1985（MLP 参数量）、y=[3,11,14,20,26] 的卷积黄金值、RF=15、以及因果性测试的两个结果（y_1..y_4 逐位不变 = 通过；未翻转版本 = 挂）。

## 侦察结论与口径决定（2026-10-31，对照印刷页 30–34 / PDF 38–42）

**原文抄录**：式(2.46) z_j^(l)=Σ_i w_ji^(l)·h_i^(l−1)+b_j^(l)、式(2.47) h_j^(l)=φ(z_j^(l))（p.30–31，2.4.1 节，图 2.13 结构图）；
式(2.62) (f∗x)(x_t)=Σ_{k=1..K} f_k·x_{t−K+k}、式(2.63) (f∗_d x)(x_t)=Σ f_k·x_{t−(K−k)d}（p.34，2.4.4 节，图 2.16 膨胀卷积+残差）。
2.4 全节**没有训练配方**（优化器/学习率/batch/epoch/初始化/早停全无），与 errata E01 一致。

**决定**（实现与视频共同遵守）：

1. **训练超参非书中给出**：tanh 隐层、线性输出、MSE、Adam(lr=1e-3, β=(0.9,0.999), ε=1e-8)、batch 64、Xavier σ=√(2/(fan_in+fan_out))、早停 patience 5。算法卡与画面角标都写「超参来源：非书中给出」。
2. **因果卷积黄金值勘误**：brief/PLAN 写 `y=[3,11,14,20,26]`；按式(2.62) 逐项展开 f=(1,2,3)、x=(1,2,3,4,5)、左侧补 2 个零，第二项是 `f2·x1+f3·x2 = 2·1+3·2 = 8`，不是 11 → 本仓黄金值 **y=[3,8,14,20,26]**。登记 `docs/09-book-errata.md` E26（「计划手算错误，非书错」）。
3. **对齐口径**：左侧补 `(K−1)·d` 个零，输出与输入等长；d=1 时 y_t 对齐 x_t。补零个数写死，错一位整条线平移（测试断言长度与首值）。
4. **翻转守卫**：式(2.62) 的核下标是 `t−K+k`（等价「翻转核再做因果卷积」）；照 PyTorch 互相关直写 `Σ f_k·x_{t+k−1}` 会看到未来。测试单独断言「翻转版 ≠ 非翻转版」，并做因果性逐位断言。
5. **感受野**：RF = 1+(K−1)·Σd = 1+2·(1+2+4) = **15**；这是标准 TCN 公式，书 p.34 正文未给公式 → 画面标注「本仓推导」。
6. **参数量按结构算死**：MLP 60→32→1 = 60·32+32 + 32·1+1 = **1985**；TCN 三层 (1→16,16→16,16→16)+输出头 = (3·1·16+16)+(3·16·16+16)+(3·16·16+16)+(16·1+1) = **1649**（残差在通道相同时取恒等；1×1 卷积书中标「可选」，本仓不加，算法卡说明）。
7. **反向传播**：两个模型都手写梯度（不引 autodiff 库）；梯度检查用中心差分 h=1e-6，相对误差 < 1e-6。RNG 自写 xorshift64*（不用 System.Random，保证跨 GHC 版本逐位可复现）。
8. **确定性**：同 seed 两次训练权重逐位相等（`Eq MlpParams` 断言）；TCN 因果性用 `==` 逐位相等，不设容差。
9. **数据泄漏口径**：标准化只用训练集 μ/σ；测试断言验证集变换后均值 ≠ 0（≈ 两段分布偏移），证明没有偷偷用验证集统计量。
10. **A股 低 R² 口径**：日频信噪比决定 R² 接近 0 是正常结果，不是实现错；视频必须并列「预测 0 基线」与「重复上一值基线」，否则整集会变成自我怀疑。
