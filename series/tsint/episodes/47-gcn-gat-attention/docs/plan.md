## Thesis

第 46 集把一只股票的五百步序列喂给循环网络；这一集换问题——**节点之间有关系时怎么算**。三十只股票、三个行业，两两算相关系数、绝对值过 0.3 就连一条边，得到一张 30 个节点、162 条边、密度极不均匀（行业内 0.9926 / 跨行业 0.0933）的图。同一张图、同一套配方（300 轮 Adam、种子 7、每个行业前 7 只训练 / 后 3 只测试），三个模型用三种态度对待它：GCN 把归一化邻接当固定算子、每层乘一次（147 参数，测试 **9/9**，损失 1.0673 → 0.0048）；GAT 让每条边的权重由打分学出来、每层重算（328 参数，**8/9**，损失停在 0.2408）；自注意力干脆不要图、所有点两两互看（816 参数，**6/9**，训练损失 0.0002 却迁移不出去）。**真正的对照是打乱邻接**：同一份代码、同一个划分，把图的节点编号重排后再训练，GCN 掉到 **1/9（0.1111）**。所以本集的结论是：图确实在起作用（9/9 对 1/9），但九个测试点里一格就是 11.1 个百分点——这个样本量撑不起「谁更好」的排名。

## Verification

看完能自己复现：

1. **归一化黄金值**：两个点、一条边的玩具图，`P = D̃^(-1/2) (A + I) D̃^(-1/2)` 退化成 2 × 2、每行 0.5 / 0.5，行和 1.0000；L = tanh、权重 1、输入 1 → **tanh(1) = 0.7616**（不是 1）。
2. **GAT 打分能被手算**：两个邻居的原始打分 [0, ln 3]，exp 后 [1, 3]，softmax 后 **[0.2500, 0.7500]**，行和 1.0000；非邻居在 softmax 前被压到 `-1.0e30`，exp 后是**精确的 0.0000**（不是 1e−13 这种尾巴）。
3. **自注意力的缩放**：d′ = 1 / 4 / 16 → 缩放系数 1.0000 / 0.5000 / 0.2500；全零输入时注意力退化成均匀的 0.5 / 0.5。没有图，所以掩码全 1——这就是「不要图」的实现方式。
4. **参数量三个数**：GCN 147（96 + 51）；GAT 328（第一层 4 头 × (5×4 + 2×4) = 112、第二层 4 头 × (16×3 + 2×3) = 216）；自注意力 816（240 + 576）。三个都和 30 只股票无关。
5. **梯度核对**：三套实现都写了中心差分数值梯度，最大相对误差 GCN **3.926e−10**、GAT **3.191e−10**、自注意力 **3.068e−10**。
6. **置换等变**：图和节点同时按同一置换重排，注意力系数也按同一置换重排，最大偏差 **5.551e−17**（< 1e−9）；同种子重跑逐位相同。
7. **打乱对照**：`shuffleGraph` 行列同时置换（边数不变、度数分布不变、仍对称），同一份代码 GCN 测试 **1/9 = 0.1111**，对真实图的 9/9。
8. **证据程序**：28 组检查全过，耗时 7.0 s，分 data 5 / gcn 5 / gat 6 / attn 5 / control 4 / train 3。

屏幕上必须出现：0.5 / 0.5、tanh(1) = 0.7616、[0.2500, 0.7500]、缩放 0.5000、参数 147 / 328 / 816、梯度 3.926e−10、置换 5.551e−17、打乱后 0.1111 对 1.0000、随机 0.3333、一格 11.1 个百分点。

## Boundary

1. **三十个节点是最好的教学尺寸，不是工业尺寸**：30 × 30 稠密矩阵能整张放进缓存、打印出来也看得清。真实图动辄上百万节点，要换稀疏格式（CSR）、邻居要采样、小批次要按子图切；本集不假装会做这些，第四页把这些「不做的事」逐条列出来。
2. **连上线不等于谁影响谁**：相关系数只说两条曲线同向或反向，不说方向、更不说因果。同行业两只股票高度相关，很可能是因为共享同一批因子，而不是一只推另一只；阈值 0.3 是人为选的——换阈值边数就变，而没有一条检查能告诉你哪个阈值对。本集把阈值当给定条件，结论只能说「在这张图上」。
3. **对齐丢了一百二十天**：原始面板 1,942 行，只在三十列都有值的交易日上算相关，剩 1,822 天，丢掉 120 天（约 6.2%）。停牌、上市晚、退市都会造成这种缺失；没有做前向填充也没有插值——宁可少算，不编数据。
4. **九个测试点，一格 11.1 个百分点**：GCN 9/9、GAT 8/9、自注意力 6/9、打乱 1/9、随机 3/9。九格里差一到三格听起来分明，换成置信区间就什么也说不出来；这一集只把机制钉住，不抢「谁更好」的结论。
5. **这不是工业级 GNN**：没有稀疏大图、没有 inductive 划分（测试节点训练时就见过特征，只是不给标签）、没有动态图（边按整段样本一次算好）、没有边特征、没有调参和早停。四个模块加起来不到两千行，全部有测试和梯度核对——它的价值是把书上那几行公式变成能跑的、能查错的代码。

## Deviations

1. **数据口径**：计划沪深 300 内按行业三组各十只、2018–2024、每只 60 日 × 单变量收益序列当节点特征；实际按证监会门类 J66 / C39 / C27 各 10 只、2018-01-02 至 2025-12-31，节点特征改成五维（每只股票的收益统计量），面板 1,942 行 × 30 列、对齐后 1,822 天。偏差写进 ts-base manifest、dist.json meta 与成片 boundary 页。
2. **阈值**：计划 0.5，实际建图用 0.3 → 162 条边（行业内 134 / 跨行业 28）。0.3 比 0.5 多留下弱边，行业块才连得起来（行业内密度 0.9926）；阈值是人为选择不是发现，boundary 页明写。
3. **划分**：计划「5 次随机切分取均值」；实际按行业切（每个行业前 7 只训练、后 3 只测试），只跑一次。行业内密度 0.9926，随机切分下每个测试节点几乎必然连着同行业的训练节点，测出来的准确率分不清是「图传了标签」还是「模型学了特征」；按行业切让每个测试节点的邻居里既有同行业也有跨行业，图的结构才真正参与预测。单次划分的代价是没法给方差，写进 boundary 第 4 条。
4. **打乱对照的口径**：计划「随机重连保度序列」；实际用 `shuffleGraph` 对行列同时做置换——边数、度数分布、对称性全不变，只把「谁跟谁相连」打乱。这比随机重连更严格地只破坏结构信息，且完全可复现（置换由种子 7 决定）。
5. **计划里的「T=500 内存 25 万 float」没进画面**：那是第 46 集的长窗口账，这一集的主读数是参数量与准确率；屏幕上换成 147 / 328 / 816 与 11.1 个百分点。
6. **thesis 改写**：计划写「打乱后回落到与无图 MLP 持平」；这一集没有单独训 MLP，最接近「无图」的是自注意力（全 1 掩码、不加图结构），它 0.6667，打乱图是 0.1111——两者不是同一个东西。所以结论改成「图确实在起作用（9/9 对 1/9），但样本量撑不起排名」，不用「回落到无图水平」这种没测过的说法。
7. **时长**：计划 24 分钟；成片 **20:30.52**（1,230.52 s）。历史区间 E42 15.4 / E43 18.8 / E44 21.5 / E45 21.5 / E46 23.1 分钟，计划分钟是粗估，实测 ±30% 正常，不改稿。
