# 64-llm-side-adapters - 只训练 0.1% 的参数：线性探测、LoRA 与语义锚点

> status: draft
> chapter: ch07 | runtime target: 16 min | algorithms: 3

## Thesis

冻结一个 70,209 参数的主干，只训练很小的一块——小到什么程度？本集把三种适配器拆开算账。**线性探测**：64 维表示接一个 65×20 的线性头，**1,300** 个参数，占主干 **1.85%**；岭回归闭式解，λ 为零时能精确复原真值（误差 **8.882e−16**），但测试相对误差 **1.0543**，比「预测均值」差 **5.4%**，同参数的随机特征头是 **1.0847**——表示里有信息，但不够多。**低秩旁路（LoRA）**：秩 4 的一对 4×64 / 64×4 矩阵，**512** 个参数、**0.73%**，B 全零时输出与冻结模型逐位相同（差 **0.0**），80 轮只把训练损失从 36.4925 挪到 36.4807（**0.03%**），测试 MSE **36.5813** 对冻结 **36.5847**——秩 4 改不动这块表示。**语义锚点**：64 个两两正交的词（偏差 **1.484e−6**），每类挑一个余弦最近的词当下标拼前缀，**0 参数**、9 个 token；准确率 **0.09**，同一任务上 1,300 参数的线性头是 **0.365**，机会水平 0.05——零参数打不过一千三。三笔账都是负结果，照实讲：参数账能一眼算清，效果账要钉好口径才敢读。

## Verification

证据程序 `evidence-ch07-adapters` 一条命令跑 19 项检查（数据 3 / 线性头 5 / 旁路 6 / 锚点 5），**19/19、107.10 s**，写 `summary.json` 与逐行 `checks.txt`。屏幕读数全部来自它：

- 数据：6,600 行收盘价 → 6,599 个收益；预训练 **3,218** 窗（1998–2014）、下游 **1,219** 窗（2015–2019），按时间切 训练 **732** / 验证 **243** / 测试 **224**。
- 主干：512 点进、64 维出，编码器 **66,113** 参数（最好第 **8** 轮、验证误差 **1.024633**）+ 冻结投影 **4,096** = **70,209**；本集一个权重都不更新。
- 线性头：参数 (64+1)×20 = **1,300**；λ=0 精确复原 w_true，最大误差 **8.882e−16**；λ 网格只在验证段选，选中 **100.0**；测试 relMAE **1.0543**（MAE **0.5887** 对预测均值 **0.5584**）；同参数随机特征头 **1.0847**。
- 旁路：参数 2×4×64 = **512**、占 **0.7293%**；B=0 时输出与冻结 P 逐位相同（最大差 **0.0000**）；秩 4 修正后合并矩阵与冻结的最大差 **6.939e−18**；训练损失 **36.4925 → 36.4807**（降 **0.03%**，92 对样本、80 轮、lr 0.001）；测试 MSE **36.5813** 对冻结 **36.5847**，变化 **0.0093%**。
- 锚点：词表 64×64 两两正交，偏差 **1.484e−6**（CSV 六位小数）；top-8 与暴力排序逐位一致 **26, 41, 20, 51, 50, 61, 52, 30**；20 类各挑 1 个词、前缀 **9** token、参数 **0**；准确率 **0.0900** 对线性头 **0.3650**、机会水平 **0.0500**；800 条合成样本（20 类 × 40）。
- 确定性：三个模块都是纯函数（无 IO、无随机数），锚点词表固定 seed 20261105，证据程序 107.10 s（含 3,218 窗预训练与 1,219 窗取表示）。

## Deviations

- D1 目标换过一次：原计划直接回归「未来 20 个收益」，线性头 1.03、随机特征头 1.05，都赢不了预测零，判定不可预测；换成 20 维累计平均绝对收益取对数后才有信号。换目标不是作弊，但要在边界页说明白——这是这一集最诚实的一段。
- D2 合成分类任务也换过一次：原任务「20 类自回归序列过编码器做线性分类」准确率 0.045 ≈ 机会水平 0.05，说明冻结编码器对这类序列不分层；改成「表示空间随机原型 + 噪声」的合成类后才分得开。失败路径保留在证据程序里，不报为主要结论。
- D3 主干不是从前几集搬来的现成编码器：本集证据程序用 1998–2014 的 3,218 窗重新预训练（512-64-512、66,113 参数、最好第 8 轮、验证误差 1.024633），之后冻结；因此屏幕口径写「这一集预训练的编码器」，不说「上一集的」。
- D4 岭回归用列主元高斯消元解正规方程，不上 SVD/QR：64+1 维、1,300 个参数的小系统，闭式解足够且无随机；λ 只加到权重对角、截距列不动，否则特征会丢掉水平信息。
- D5 LoRA 秩固定 4（64 维的 6.25%，512 参数、占 0.73%）：80 轮只降 0.03%，测试 MSE 与冻结模型差 0.0093%——秩 4 的修正改不动这块表示。这是负结果，不换更大的秩来「救」结论。
- D6 锚点词表用随机正交设计而不是语义嵌入：64 个 64 维向量两两正交（偏差 1.484e−6），0 参数可完全复现；代价是词与任务语义无关，准确率 0.09 只比机会水平高一点，同一任务上线性头 0.365。
- D7 时长：目标 16 min，旁白实测 17:33（1053.48 s），按实测走，不剪内容。
- D8 数据边界：一只股票（sz000001）、单一切分（无交叉验证）、LoRA 只有 92 对样本、锚点任务是表示空间合成类；结论只在条件内成立，出了这些条件结论待验证。
