## Thesis

教材第 46 页 3.3.3 只留了一句话：「线性模型参数少，效果不差。」表 3.1 把线性结构与 Transformer 并排，最后一列是参数量：7.05e4、1.397e5、4.5e3。**没有输入长度、没有输出长度、没有训练配方、没有归一化、没有可复现的数字**（errata **E34**）；DLinear 的分解式与 FITS 的频域做法都要回到原论文 [14][17] 才拿得到。

本集用同一根线性骨干写三个结构，把「参数量」和「精度」拆开。

第一，三个模型只改坐标，不改骨架。共享权重线性是 `ŷ = W x + b`，96 进 24 出共 **2,328** 个参数；DLinear 先做 25 日移动平均分解、两条支路各接一层线性，共 **4,656**；FITS 做 rFFT、保留前 24 个频点、在频域乘一个 48×48 矩阵再逆变换，共 **2,352**。三者都还是「输入乘矩阵加偏置」。

第二，DLinear 的 4,656 个参数在函数意义上等价于 2,328。因为 `t + s = x`，两条支路又都线性，合成后 `ŷ = (W_t A + W_s (I − A)) x + (b_t + b_s)`；令 `W_t = W_s = M` 立刻退化成共享线性。证据里 k = 1 退化实验的最大差距是 **0**（seamless: R=1 时 AvgPool 恒等，季节恒零）。它比共享线性好 **3.32%**（日线 MAE 148.611 vs 153.716），只能归因于优化路径（两条支路梯度不同、Adam 步长不同、早停位置不同），不能归因于容量。

第三，三个模型都没赢最朴素基线。日线 24 步 MAE：最后一个值 **142.074**，DLinear **148.611**，FITS **150.341**，共享线性 **153.716**；五分钟线：最朴素 **42.6948**，FITS **45.5850**，DLinear **45.8971**，共享线性 **46.2119**。本集不制造翻盘叙事，只主张「参数少一个数量级时误差还贴身」。

一句话进画面：**结构换来的是可解释与可优化，而不是必然更高的精度。**

## Algorithms

- ch3-linear-shared — 共享权重线性（`TsBase.Algos.Ch03.LinearShared`）：`ŷ_k = b_k + dot(w_k, x)`，w 行主序拼成 F×H，`sharedBatch` 对 N 路输入一次映射；解析梯度按扁平参数 [W; b] 排布，系数 2/(N·F)。
- ch3-dlinear — 趋势/季节分解线性（`TsBase.Algos.Ch03.DLinear`）：`dlinearDecompose k x` 只接受奇数 k ≥ 1，两端复制端点填充 (k−1)/2 个点；`t + s = x`，两条支路各自 `W·t + b` 后相加；偶数核、k < 1、空输入都返回 `Left`。
- ch3-fits — 频域线性（`TsBase.Algos.Ch03.Fits`）：`fitsBins` 输出前 R 个复频点的实部/虚部（虚部取负号）；`fitsBasis` 预计算 F×2R 的逆变换基（行优先，t = i div 2R，a = i mod 2R，DC/Nyquist 权重 1/n，其余 2/n）；`u = W z + b, ŷ = B u`，只保留最后 F 行。
- 训练与评分口径写死在 `app/Ch03LinearEvidence.hs`：Adam 全批量、lr 0.01、最多 120 轮、耐心 12、minDelta 1e−9、零初始化、训练窗步长 2、验证窗全用、按窗实例 z-score、反变换后算 MAE。

## Boundaries

表中 7.05e4 / 1.397e5 / 4.5e3 是论文设置下的参数量，输入输出长度、通道数、训练配方都未公布，本集只在量级上引用（C 级证据），**不声称复现表 3.1**。我们的 2,328 / 4,656 / 2,352 是按 H = 96、F = 24、R = 24 算出来的，与书中数字不可直接对比。

DLinear 的分解式不在教材里，出自原论文 [14]；FITS 的通道混合与插值频率处理**没有实现**，本集只有「rFFT → 线性层 → 逆基」这一条主线，低通振铃也没有额外抑制。三个模型共用同一套学习率、轮数、早停，没有做逐模型超参搜索；排序反映结构差异，但也可能被这组超参偏袒。

样本只有八条 A 股日线与一只股票的五分钟线，来自同一家数据源；没有美股、期货、外汇，也没有多变量通道。五分钟线的模型排序对学习率敏感，画面只主张「三条线性模型彼此接近」，不主张 FITS 普遍最优。

最朴素基线在日线与五分钟线上都最低，这是本集要正面呈现的结果：线性结构在这个设定下换来的是参数量与可解释性，不是更高的精度。下一集（E20 卷积看时序）继续用同一套证据纪律追问「多出来的结构到底多学到了什么」。
