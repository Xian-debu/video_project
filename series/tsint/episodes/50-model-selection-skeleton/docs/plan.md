## Thesis

第 49 集换的是**表示**；这一集换的是**问题**：不再调一个模型，而是让机器在一批候选里自动挑一个。股票池沿用上一集的 **20 只 HS300 行业分层股票**（每个行业门类一只），每只 **2,412–2,431 根**日线，按 **2022-01-01 / 2024-01-01** 切成训练 / 验证 / 测试（训练 1,686–1,705 根、验证 483–484 根、测试 242 根）。候选池 **10 个**：naive、drift30、exp0.2、exp0.5、AR(1)、ridge5(λ=1e-3)、ridge5(λ=1)、SAR(12)、SAR(5)、hmean5。五个指标黄金值先钉住实现：**MAE 0.5 / MSE 0.4167 / RMSE 0.6455 / MAPE 27.7778% / Accuracy@3 0.6667**。

结论分三层。第一，**指标会换冠军**：20 只里有 **10 只**（正好一半）在 MAE 与 MSE 下选出的最优候选不同，所以「主指标用哪个」本身就是一个必须写下来的假设，本集取 MAE。第二，**池子决定天花板**：以全池 10 个候选在测试集上的最优为真值，池子 3 个候选覆盖真值最优 **0.75（15/20）**，池子 5 个覆盖 **0.85（17/20）**，全池 **1.00**；但验证集 argmin 的 Hit@1 只有 **0.50 / 0.50**，全池遍历 **0.55**，Hit@2 **0.60**、Average Rank **2.35** —— 扩池把上限抬了 **0.10**，命中率**一点没涨**，计划里「池 3 → 5 让 Hit@1 至少 +0.15」**不成立**（见 Deviations D3）。原因是池内的候选太像：naive 与 AR(1)、两个岭回归、SAR(5) 的测试 MAE 都挤在 **10.31–10.49**，验证集上分不出高下。第三，**策略可以很便宜**：两阶段预筛（季节特征锁 + 验证段前 120 点粗排 Top-4，再在全验证段精排）把评测点从 **96,790** 降到 **62,716**（省 **35.2%**），Hit@1 与全池遍历持平（**0.55 = 0.55**），Top-4 召回真值最优 **0.85**。网格侧还有一处算术更正：七维网格 **3·3·2·2·3·3·2 = 648**，锁住 m / d / D 之后剩 **81**（1/8），计划写的 54 与自身维度矛盾（见 Deviations D1）。

一句话：**指标决定冠军是谁，池子决定天花板，策略决定代价；在这个池子里，便宜的选择器已经够到全池遍历的水平，但天花板本身被验证噪声锁住了。**

## Verification

看完能自己复现：

1. **五个黄金值手算**：真值 [1,2,3]、预测 [1.5,2,2] → MAE **0.5**、MSE **0.4167**、RMSE **0.6455**、MAPE **27.7778%**、Accuracy@3 **0.6667**；RMSE > MAE（平方放大残差的性质）与 MAPE 跳过近零样本两条单独断言。
2. **网格算术**：七维 **3·3·2·2·3·3·2 = 648**；锁 m / d / D 后自由维是 p / q / P / Q，**3⁴ = 81**，1/8；gridSearch 对 81 个组合返回 81，全拟合失败返回 0；AIC 黄金值 **206**（2×3 − 2×(−100)），同一组残差下 AIC 随 RSS 单调。
3. **覆盖与命中**：coverage **0.75 / 0.85 / 1.00**（15 / 17 / 20 只）；Hit@1 **0.50 / 0.50 / 0.55**（10 / 10 / 11 只）；Hit@2 **0.60**、Average Rank **2.35**，且 Average Rank 落在 [1, 5]、Hit@2 ≥ Hit@1 两条自洽性断言成立。
4. **两阶段预筛**：评测点 **96,790 → 62,716**（省 **35.2%**，口径 10×480/只 vs 10×120 + 4×480/只，其中季节锁把 m=4 的 20 只各剔掉 SAR(12) 与 SAR(5)，共 **40** 个候选）；预筛 Hit@1 **0.55** 与全池遍历 **0.55** 的差为 **0 < 0.05**；Top-4 召回真值最优 **0.85**。
5. **指标换冠军**：逐只比较 test MAE argmin 与 test MSE argmin，**10 / 20** 只不同（flips = 10）；这条不是缺陷，是「指标即假设」的直接证据。
6. **逐只读数**：20 只股票的真值最优分布是 naive **14**、drift30 **2**、SAR(12) **2**、AR(1) **1**、SAR(5) **1**；每一只的四套选择（池 3 / 池 5 / 全池 / 预筛）都记进 per-stock 表，页面上能对上号。
7. **负结果**：计划预期 Hit@1 +0.15，实测 **+0.00**；覆盖面确实 +0.10。证据程序 **26 项检查全过、耗时 21.4 s**，分组 data 4 / metrics 5 / pool 6 / prefilter 4 / grid 3 / demo 4。

屏幕上必须出现：**0.5 / 0.4167 / 0.6455 / 27.7778 / 0.6667**、**648 → 81**、**206**、**0.75 / 0.85 / 1.00**、**0.50 / 0.50 / 0.55**、**96,790 → 62,716**、**35.2%**、**10/20**、**14 / 2 / 2 / 1 / 1**、26 项检查与 21.4 s。

## Boundary

1. **二十只股票不是二十个行业面板**：每个门类只取一只（有效交易日最多的那只），所以「20 个行业」实际是 20 条序列；换一批股票，覆盖率和 Hit@1 都会变。这一集比的是同一个池子里的**相对关系**，不是行业结论。
2. **十个候选是手挑的**：池子决定了结论的适用范围，更优的模型可能不在池子里；「扩池只抬上限」这个说法只对这 10 个候选成立。
3. **一步预测**：只预测下一个交易日，多步预测的误差会累加，指标要重算；本集的 Hit@1 不能外推到多步。
4. **单指标**：主指标 MAE 是选的，不是推出来的；换成 Sharpe、胜率或 MSE，冠军会换（本集有一半的股票会换）。指标的选择本身就是一个假设。
5. **日线噪声与样本量**：每只两千多根、验证段 483 点，20 只合计不到一万个验证点；Hit@1 的置信区间很宽（10/20 与 11/20 的差别不显著），所以「持平」要读成「分不出差别」，不是「精确相等」。
6. **负结果照实记录**：计划里「扩池让 Hit@1 至少 +0.15」没有成立，实测 **+0.00**；这个负结果比正结果更有用，它说明先要修的是验证信号，不是搜索策略。

明确不做：元学习 / 多目标优化 / 在线滚动重训 / 跨市场验证。

## Deviations

1. **网格 54 → 81（计划算错）**：计划写「648 组合锁到 54（≈1/12）」，但七维是 3·3·2·2·3·3·2，锁 m / d / D 后剩 p / q / P / Q 四维，**3⁴ = 81**（1/8）。54 与自身维度不自洽，全片按 **648 → 81** 报。
2. **SARIMA 去季节项与 AR(1) 等价**：计划的 SARIMA(1,0,0)(0,0,0,12) 把季节项全置零后与 ARIMA(1,0,0) 是同一个模型，池子里会重复计数；实现改成 **AR(1) + 季节 AR(1)**（sar12 / sar5 两档，m = 12 / 5），与 naive、drift30 明确区分。
3. **thesis 不成立（最重要的偏差）**：计划「池 3 → 5 让 Hit@1 至少 +0.15」，实测 **0.50 → 0.50（+0.00）**，全池也只有 0.55。成立的是覆盖率 **0.75 → 0.85（+0.10）**。全片改口为「池子给天花板、验证噪声卡命中、预筛省 35.2% 不掉点」，并把这个负结果写进讲稿与边界。
4. **预筛规则修正**：初版「m = 4 时只留 id 小于 7」会连带删掉 hmean5（它跟季节周期无关），语义不对；改成「m = 4 时剔除 SAR(12) 与 SAR(5)」，剔除数从 60 变 **40**，评测点读数随之更新。
5. **主指标选择**：计划没有指定主指标；因为 flips = 10/20，必须显式选一个。取 MAE（与「预测误差」这个目标对齐），MSE 只做稳健性检查，并把这条写进边界。
6. **Hit@2 / Average Rank 的口径**：Hit@2 在池 5 上算（真值最优属于池 5 验证排序前 2），Average Rank 也是池 5 内的名次；全池遍历只报 Hit@1。这两个数不进主结论，只做选择器分辨力的辅助读数。
