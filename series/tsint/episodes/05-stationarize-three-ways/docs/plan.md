## 五条判断

1. 三条路里只有差分改变积分阶。差分是累加的逆运算：价格是收益的累加，差分把生成机制还原。实测随机游走水平方差 2458.29，差分方差 1.0127（步噪声方差 1）。
2. Z-score 不是平稳化。它是仿射变换，自相关与原来完全相同（0.994136630574，差 2.4e-15），只把均值方差挪到 0 和 1。
3. 对数只治异方差。乘性噪声序列的相关从 0.9395 降到 −0.3706；趋势与积分阶原样保留。
4. 差分有固有代价：放大噪声、丢观测（d 阶丢 d 个点）、要求长度大于季节周期。这些写进错误类型，不靠调用方自觉。
5. 书把 Z-score 列在平稳化小节，本片当场纠正：叫标准化，不叫平稳化。

## Claims

- 只有差分改变积分阶（书中 p.19 的三条并列没有区分这一点）。
- Z-score 是标准化不是平稳化（本片判断，书中位置有误导）。
- 对随机游走，差分方差等于步噪声方差 σ²，不是 2σ²；2σ² 是对白噪声做差分的方差，常见混淆。
- 总体口径 1/T 与样本口径 1/(T−1) 不同，本片与书中式 2.5 一致。
