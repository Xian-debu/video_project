## Thesis

上一集把分数算出来了，这一集把分数切成判断。同一批异常、同一串分数，只换切点：固定 3σ 的 F1 是 0.6957，训练段 1% 分位是 0.7273，SPOT 是 1.0000。差别不在模型——三种切法用的是同一个分数，模型这一集根本不存在。前三者都在尖峰上好看，换成 2–4 个局部 sigma 的中等偏移，三种切法 F1 全部低于 0.1：阈值只能切分数，不能替分数看见东西。这一集把阈值三兄弟（固定 / 分位 / SPOT）、一个逻辑回归分类器、以及最笨的统计基线（移动平均）实现并测透，二十八个检查全部通过。

## Boundaries

四条边界：一，阈值不是超参数，是口径的一部分——同一串分数换阈值就换 F1，所以报 F1 必须报阈值；二，SPOT 只在厚尾上赢，尾部不是帕累托就会偏，股票日收益的厚尾是产业结构，换市场结论要重测；三，全局 z 分数看不见局部波动，中等偏移实验已证明三种切法全低于 0.1，要抓得先换分数（滚动窗口尺度是后面的事）；四，分类器的上限是样本量，训练段几十个正样本学不出稳定边界，它输给手写 z 分数不丢人。三笔欠账：无监督方法（K 均值 / LOF / 孤立森林，不用标签怎么定义异常，F1 怎么算）、序列模型（自回归 / 状态空间，把时间结构用起来）、阈值自适应（今天固定，明天呢）——第一笔下一集就还。
