## Thesis

时间轴压完，换到通道轴：同一件事有三种代价完全不同的补集。混合 MLP（TSMixer）在时间轴与通道轴各做一次矩阵乘，96×96 + 8×8 + 96×8 的门，10,048 个参数；路由注意力把 64 个通道投到 c=4 个槽，参数 c·d=256，交互从 N²=4096 降到 c·N=256，少 16 倍；动态聚类 k=4 时参数 k(H+1)F = 9,312，每簇一套从历史到预测的线性权重，分配按当前窗口重算。三者都不训练时都抓不到行业标签——本集只量容量与结构，不量效果。

## Verification

证据口径：不训练模型、不比较预测误差，只测结构与真实数据上的性质。38 项检查全部通过（38/38），底层 95 套测试 / 1,313 条断言零失败（本集新增 62 条）。

- 双轴混合（20 条断言）：参数量 10,048 = 96² + 96×8 + 8²；零权重恒等误差 0；2×2 手算矩阵积误差 0；通道等变残差 1.78e-15、时间等变残差 7.11e-15（阈值 1e-11，均一门前提）；W1 对角带宽质量 0.1721，均匀基线 1,560/9,216 = 0.1693；W3 通道块质量 0.2173，均匀基线 0.25；8 通道面板同组相关 0.6959 vs 跨组 0.4445，行业块质量 0.3429。
- 路由注意力（21 条断言）：行和误差 2.22e-16；c=1 时权重全为 1（误差 0）；N=3、c=1、d=1、α=1 手工值 2（误差 0）；置换误差 2.22e-16；复杂度 256 vs 稠密 4,096，比值 16；参数量 256（按书的 d=32 是 128）；未训练随机槽纯度 0.1562 / ARI 0.0074，中心化 PCA 槽纯度 0.2031 / ARI 0.0108，四个槽塌成一个。
- 动态聚类（21 条断言）：k=4 参数 9,312 = 4×97×24，k=10 为 23,280；合成 3 簇 12 通道纯度 1.0；真实 64 通道单窗纯度 0.3438 / ARI 0.0567；5 个窗 ARI 均值 0.0575，减市场共模后 0.0959（纯度 0.3219 → 0.3781）；减共模后同行业 0.0637 vs 跨行业 −0.0234；无空簇。
- 数据检查（5 条）：8 通道面板 2,657 行、64 通道面板 2,659 行 / 64 通道 / 10 行业、2,658 个收益、两个 sha256 与面板清单一致。

屏幕数字：10,048、256 vs 4096、1.0（合成纯度）、9,312，以及 1.78e-15 / 7.11e-15 两条等变残差。

## Boundaries

四条边界：没有训练，任何"哪个模块更懂通道"的说法都不成立；行业信号在日频相关里只有约 0.05 的对比，市场共模占 43%，减共模后 ARI 翻倍也仍然很低；相关不是因果，减第一主成分只减掉一个方向，聚类分出的簇不等于行业；只有一个市场、日频、2015–2025，外推不到别的频率与市场。三笔欠账：算法卡、routerAttn / clusterDemo 的一键 demo、端到端训练对照。
