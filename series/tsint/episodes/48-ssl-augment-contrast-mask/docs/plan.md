## Thesis

第 47 集用一张行业图把三十只股票连起来；这一集把标签本身拿掉。池子里 **1,000 条 60 日窗口全都没有标签**，有标签的只有 **50 条**（电子 17 / 银行 17 / 券商 16），多数类基线 **0.34**。三种自监督方法用同一套配方各训练一个 32 维编码器（种子 7、全批量 Adam）：**对比学习** 12 轮、批 32、参数 **3,008**，InfoNCE 从 1.6298 降到 0.5894，冻结编码器后线性探针（30 条训练 / 20 条测试）拿到 **0.45（9/20）**；**掩码重构** 10 轮、批 64、参数 **5,852**，重构损失压到 0.0009，探针只有 **0.35（7/20）**；**未训练**的随机编码器是 **0.30**。增强强度是第二根杠杆：抖动、缩放、翻转都保住 0.45，**时间弯曲到 20 个百分点就掉到 0.20**，比多数类基线还低。所以本集的结论不是「对比比掩码强」——二十条测试一格就是 5 个百分点，两个方法差两格——而是：**自监督信号确实把无标签窗口变成了可用的特征，但信号选错、强度用猛，会把特征打回基线以下**。

## Verification

看完能自己复现：

1. **InfoNCE 两个黄金值**：正例相似度 1、两个负例 0、τ = 0.2 → 权重 [0.9802, 0.0099, 0.0099]，损失 **0.5514**；三条全零相似度时退化成均匀分布，损失 **ln 3 = 1.0986**（不是 1.0，也不是 1.1）。同一条样例里 τ 从 0.2 降到 0.05，损失从 **1.0559 降到 0.0003**。
2. **对比损失确实在下降**：12 轮训练 1.6298 → **0.5894**，用时 4.3 s；探针 0.45 高于基线 0.34，高出三格。
3. **重构黄金值手算**：x = [1,2,3,4]、遮住第 3 位、预测全 0 → (2² + 2² + 1²) / 3 = **9.0**；完美重构精确为 0；**|M| = 0 必须报错**（损失无定义）。
4. **掩码布局**：15% 随机点 + 10% 的连续块（块长 6），实测平均掩码率 **0.1533**；遮住处填 0，另给一路 0/1 标记，输入 120 维、输出 60 维；参数 **5,852 = (32×120+32) + (60×32+60)**。
5. **增强的可复现性**：σ = 0 时 jitter 逐元素还原；flip 两次回到原序列；同种子 jitter 逐位相同；mixup λ = 0.5 时 [1,2] 与 [3,4] → **[2,3]**；warp 20 个百分点后 60 个采样位置**严格递增**。
6. **三种对照**：未训练编码器探针 **0.30**（6/20，与基线 0.34 相当）；标签整体错位后 **0.20**（4/20，不高于基线）；窗口顺序置换后编码输出不变，置换误差 **0**（编码只依赖单条序列）。
7. **证据程序**：28 组检查全过、耗时 **10.8 s**，分 data 5 / augment 5 / contrast 6 / mask 5 / control 4 / train 3。

屏幕上必须出现：0.5514 / 1.0986、损失 1.6298 → 0.5894、参数 3,008 / 5,852、探针 0.45 / 0.35 / 0.30、基线 0.34、多数类 17/50、warp 0.20、掩码率 0.1533、重构 9.0、一格 5 个百分点。

## Boundary

1. **一千条不是一千条独立样本**：窗口 60 日、步长 20 日，相邻两条共享 40 天，有效独立样本只有三分之一左右；再叠上同一只股票的多条窗口高度相关，「1,000 条」听起来不少，实际信息量小得多。结论要按这个打折扣。
2. **两边都没收敛**：对比 12 轮、掩码 10 轮，损失曲线到最后一轮仍在下降（对比 0.5894、掩码 0.0009 都还是正的），而探针是训到 300 轮收敛的。所以本集比的是「同样限时下三种监督信号谁更有用」，不是「各自训到最好谁更强」；再给十倍轮数，两个探针都会更高，到那时比的就不是方法而是预算。
3. **二十条测试，一格 5 个百分点**：0.45 对 0.35 是两格，0.35 对 0.34 只有一条测试的差别。二十条样本给不出置信区间，这一集只报方向，不报排名；warp 的 0.20 与 0.30 之间也一样，能说的是「掉到基线以下」，不能说的是「掉了几格」。
4. **warp 只试了一个强度**：20 个百分点是唯一测过的点，5 / 10 / 15 都没跑；也许 5 个点是好的。这一集只报告一个点、不给曲线，也不宣称「时间弯曲一定有害」。
5. **这是最小实现，不是工业级系统**：300 只股票的一个快照、1,000 条窗口、两层编码器（3,008 / 5,852 参数）、一个三分类探针；没有大模型、没有全量数据、没有超参搜索、没有跨数据集验证。它的价值是把三种自监督机制写成能跑、能对账的代码，不是刷榜。

## Deviations

1. **股票池**：计划「沪深 300 全部成分股 2015–2025」；实际湖里只有 2026-10-30 一期 `index_members` 快照，用快照 300 只代替历史成分，偏差写进导出 manifest 与 boundary 页。
2. **窗口采样**：计划「1,000 条无标签（缩小 1/3）」；实际按每只股票各自连续有效段切窗（步长 20）、候选窗口洗牌取前 1,000 条，不是固定 3,000 窗口均匀子采样。
3. **探针来源**：计划「50 个有标签随机抽自 300 只」；实际从 C39 / J66 / J67 各取 17 / 17 / 16 只、每只取中间窗口，保证三分类都有样本且 50 条互不重复。
4. **异常窗口**：计划未提；实际剔除窗口内单日 `|收益| ≥ 0.5` 的异常段（拆股/错价），未做前向填充或插值。
5. **对比批大小**：计划两套预训练用同一批大小；实际对比 32、掩码 64（掩码要拼 120 维输入，显存/内存预算不同），其余超参（种子 7、Adam、全批量）一致，learning rate 分别 0.01 / 0.005。
6. **时长**：计划 26 分钟；成片 **24:06.48**（1,446.48 s）。历史区间 E43 18.8 / E44 21.5 / E45 21.5 / E46 23.1 / E47 20.5 分钟，计划分钟是粗估，实测 ±30% 正常，不改稿。
