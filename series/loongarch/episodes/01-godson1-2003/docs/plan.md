# 龙芯1号：先证明能跑

## 一页事实

- 论文：胡伟武 等，《龙芯1号处理器结构设计》，计算机学报 2003, 26(4)（data/paper.txt）
- 硬事实：0.18µm、200MHz 启动 Linux 2.4、最高 266MHz、一次流片、成品率 >80%、功耗 0.4–0.5W、8KB 两路指令 Cache、七段流水、单发射、精确例外、缓冲区溢出防护。
- 结论：龙芯1号的价值不在分数，而在把“设计—验证—流片—跑系统”的整条链路走通；短板同样清楚：单发射、Cache 太小、编译器与生态未跟上。
- 目标观众带走：自主通用 CPU 的第一道门槛是“能不能跑通”，不是“跑得多快”。

## 证据与实验

- A 级实验：build/queue_sim.py，周期级模型；20 拍 load 缺失 + 16 条独立 ALU；顺序 42 拍，窗口 2/4/8/16 为 34/30/28/27 拍，加速 1.24/1.40/1.50/1.56 倍。明确标注“不是龙芯1号实测”。
- 数字核对：data/claims.json 9 条，claims_check 全部命中 paper.txt 连续切片；SPEC 分数只作 2003 年绝对值记录，不跨代比较。
- 两处原文分栏断行：最高频率句取“266MHz”连续片段；“Cache 过小”句取摘要连续片段，均在 claims note 说明。
